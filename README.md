# E-Analytic

Платформа антикоррупционной аналитики. Прототип на реальном стеке, дизайн и
моторика — дизайн-система ADATA 2026.

```bash
npm install
npm run dev        # http://localhost:3000
npm run typecheck
```

**Живой прототип: https://morrison767.github.io/ean/**

Вход: кнопка «Войти в демо-режиме» — пароль не проверяется, сеанс это флаг в
localStorage.

## Публикация

Пушь в `main` → workflow `.github/workflows/deploy-pages.yml` собирает статику
и публикует на GitHub Pages. Экспорт включается переменной `GITHUB_PAGES`;
`basePath` подставляется из имени репозитория, поэтому workflow переносится
в другой репозиторий без правок.

Деплой идёт только с `main`: окружение `github-pages` не принимает публикацию
с других веток.

## Откуда взялись данные

Исходников прежней версии не сохранилось — только собранный бандл. Все демо-данные
извлечены из него скриптом `scripts/extract-legacy-data.mjs`: 18 структур,
~93 КБ (люди, компании, декларации ВЭД, ЭСФ, закупки, транзакции, выписки,
схемы связей, журнал). Скрипт оставлен в репозитории — он документирует
происхождение фикстур и позволяет добрать поле, если понадобится.

Прежняя сборка лежит в `legacy/` как эталон контента. В приложении не участвует.

## Слой данных

Компоненты не знают про localStorage. Цепочка одна:

```
src/data/seed/*.json  →  src/data/seed.ts  →  src/lib/storage.ts  →  src/store/use-app.ts
```

`SEED_VERSION` в `seed.ts` поднимается при любом изменении формы данных:
хранилище сверяет версию и пересевает базу, вместо того чтобы падать на записи
по старой модели. Когда появится настоящий API, меняется `storage.ts`, а не экраны.

Гидратация отложена до монтирования (`hydrate()` в `AppShell`): на сервере
localStorage нет, и синхронное чтение разошлось бы с серверной разметкой. Штатный
`persist` от Zustand по этой же причине не используется.

## О shadcn/ui

Компоненты вендорены в репозиторий — это штатная модель shadcn. CLI не
используется намеренно: его текущая мажорная версия целится в Tailwind v4 и
Base UI, а при `init` перезаписывает `globals.css`, `tailwind.config.ts` и
`lib/utils.ts` — то есть весь слой токенов ADATA. Компоненты собраны на Radix
и стилизованы токенами ДС.

Не запускайте `npx shadcn add` без проверки: он снова тронет конфиги.

## Моторика

Все длительности, кривые и пружины — в `src/lib/motion.ts`, в разметке чисел нет.

- смена экрана — `screenEnter`, короткий подъём, только вход;
- карточки раздела — каскад `Stagger`, 60 мс между элементами;
- вкладки, сегменты, метка активного раздела, переключатель темы — общий
  элемент через `layoutId`, поэтому индикатор переезжает, а не мигает;
- показатели — `Counter`, число набегает от нуля и только в кадре;
- `prefers-reduced-motion` уважается везде.
